# Glossaire Raily 

## 🚂 Vocabulaire du jeu

*À compléter. Suggestions de termes à définir (extraits de [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] et [[cours_1/Inertcult_Erick/Version du jeu/Val Idee dev V1]]) :*

### C

- **Compagnie (ferroviaire)** : entité jouable (4 au total). Voir [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] §Compagnies.
- **Checkpoint** → voir *Gare*.
- **Core loop** : boucle de jeu fondamentale. Voir [[cours_1/Inertcult_Erick/note and more/more/to-do/to-do V1]] §1.

### D

- **Duel** : affrontement de 3 questions entre deux joueurs en croisement. Voir [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] §Duel, inspiré de [[cours_1/Inertcult_Erick/Jeux/12 coup de midi]].

### G

- **Gare** : point de passage fixe sur la carte offrant ressources / bonus. Voir [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] §Gares.

### M

- **Malus** : carte à effet négatif. Voir [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] §Système de ressources.
- **MVP** (*Minimum Viable Product*) : version minimale testable du jeu. Voir [[cours_1/Inertcult_Erick/note and more/more/to-do/to-do V1]] §2.

### P

- **Pile A / B / C** : piles de cartes-questions correspondant aux 3 zones (Amérique du Nord / Centrale / Sud).

### R

- **Rail** : élément posé sur le plateau pour matérialiser l'avancée d'un joueur.
- **Ressource** : unité de compte déterminant le gagnant final.

### S

- **Sabotage** : action consistant à emprunter le trajet d'un adversaire pour détruire ses rails. Voir [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]] §Sabotage.

### T

- **Tycoon** : modèle de jeu centré sur l'accumulation de ressources. Voir [[cours_1/Inertcult_Erick/note and more/note/Note 1]] et [[cours_1/Inertcult_Erick/Version du jeu/Val Idée Dev V2]].

### Z

- **Zone** : l'une des 3 grandes régions du plateau (Amérique du Nord, Centrale, Sud).
